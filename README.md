# Train-Station-Manager
A C++ console-based Train Station Manager game demonstrating Stack, Queue, and Linked List data structures. Players manage incoming trains, arrange their departure order, complete levels, and earn scores while learning fundamental DSA concepts.

## How to Play
Download 'DSA_Game_Train_Station_Manager.exe' from the repository and run it on a Windows computer.
